# Claude Code JSONL Transcript Schema

This document describes the structure of JSONL transcript files generated by Claude Code.

## File Location

```
~/.claude/projects/<project-hash>/<session-id>.jsonl
```

Each line is a JSON object representing a message in the conversation.

---

## Message Types

| Type | Description |
|------|-------------|
| `user` | User prompts and tool results |
| `assistant` | Claude's responses |
| `system` | System messages (hooks, commands) |
| `queue-operation` | Background task notifications |
| `file-history-snapshot` | File state snapshots for undo |

---

## Common Fields

All messages include these fields:

| Field | Type | Description |
|-------|------|-------------|
| `type` | string | Message type (see above) |
| `uuid` | string | Unique message ID |
| `parentUuid` | string \| null | Parent message for threading |
| `sessionId` | string | Session UUID |
| `timestamp` | string | ISO 8601 timestamp |
| `cwd` | string | Working directory |
| `version` | string | Claude Code version (e.g., "2.1.6") |
| `gitBranch` | string | Current git branch |
| `isSidechain` | boolean | Branched conversation flag |
| `userType` | string | "external" |
| `slug` | string | Session slug (appears after first response) |

---

## User Messages

User messages have `type: "user"` and contain either a prompt or a tool result.

### User Prompt (string content)

```json
{
  "type": "user",
  "uuid": "09e1f046-2a00-44cf-8935-dbdf0d37c216",
  "parentUuid": "ad44775c-9cc3-44c7-b103-8b8a43a438e2",
  "sessionId": "f0fa7faf-f147-4745-bd3d-2e33a785167c",
  "timestamp": "2026-01-13T07:45:42.266Z",
  "cwd": "/Users/sagar/work/project",
  "version": "2.1.6",
  "gitBranch": "main",
  "isSidechain": false,
  "userType": "external",
  "message": {
    "role": "user",
    "content": "Help me write a function to parse JSON"
  }
}
```

### User Prompt (list content)

Content can also be a list of blocks:

```json
{
  "type": "user",
  "uuid": "13f5ed38-f86c-4e9e-a308-fc007fc3805e",
  "message": {
    "role": "user",
    "content": [
      {
        "type": "text",
        "text": "[Request interrupted by user for tool use]"
      }
    ]
  }
}
```

### Tool Result

Tool results are user messages with `tool_result` content:

```json
{
  "type": "user",
  "uuid": "71b60e49-29bd-494b-88fb-e2b11ba4b281",
  "parentUuid": "e48dad73-20eb-408f-af39-9f3321f1eafa",
  "sessionId": "f0fa7faf-f147-4745-bd3d-2e33a785167c",
  "timestamp": "2026-01-13T07:47:24.192Z",
  "message": {
    "role": "user",
    "content": [
      {
        "type": "tool_result",
        "tool_use_id": "toolu_01WWRCHMDLo4nMSi7gLxcvx4",
        "content": "<tool_use_error>File does not exist.</tool_use_error>",
        "is_error": true
      }
    ]
  },
  "toolUseResult": "Error: File does not exist.",
  "sourceToolAssistantUUID": "e48dad73-20eb-408f-af39-9f3321f1eafa"
}
```

### Additional User Fields

| Field | Type | Description |
|-------|------|-------------|
| `imagePasteIds` | number[] | IDs of pasted images |
| `thinkingMetadata` | object | `{level, disabled, triggers}` |
| `todos` | array | Current todo items |
| `toolUseResult` | string | Tool result summary |
| `sourceToolAssistantUUID` | string | UUID of assistant that triggered tool |

## Assistant Messages

Assistant messages have `type: "assistant"` and contain Claude's response.

```json
{
  "type": "assistant",
  "uuid": "e48dad73-20eb-408f-af39-9f3321f1eafa",
  "parentUuid": "6742d2ff-1413-47ad-9a08-7aa068387420",
  "sessionId": "f0fa7faf-f147-4745-bd3d-2e33a785167c",
  "timestamp": "2026-01-13T07:47:22.092Z",
  "requestId": "req_011CX51PqGNe6YjRNH7Wigiy",
  "message": {
    "model": "claude-opus-4-5-20251101",
    "id": "msg_01LBacPoK3WiNVcDWqPu7p8i",
    "type": "message",
    "role": "assistant",
    "content": [
      {
        "type": "text",
        "text": "I'll read that file for you."
      },
      {
        "type": "tool_use",
        "id": "toolu_01WWRCHMDLo4nMSi7gLxcvx4",
        "name": "Read",
        "input": {
          "file_path": "/Users/sagar/work/project/file.py"
        }
      }
    ],
    "stop_reason": "tool_use",
    "stop_sequence": null,
    "usage": {
      "input_tokens": 9,
      "output_tokens": 3,
      "cache_read_input_tokens": 14052,
      "cache_creation_input_tokens": 12391,
      "cache_creation": {
        "ephemeral_5m_input_tokens": 12391,
        "ephemeral_1h_input_tokens": 0
      },
      "service_tier": "standard"
    }
  }
}
```

### Content Blocks

The `message.content` array contains these block types:

| Block Type | Fields | Description |
|------------|--------|-------------|
| `text` | `text` | Text response |
| `tool_use` | `id`, `name`, `input` | Tool invocation |
| `thinking` | `thinking`, `signature` | Extended thinking |

### Token Usage

| Field | Description |
|-------|-------------|
| `input_tokens` | New tokens sent |
| `output_tokens` | Tokens generated |
| `cache_read_input_tokens` | Tokens read from cache |
| `cache_creation_input_tokens` | Tokens written to cache |

**Total context = input_tokens + cache_read_input_tokens + cache_creation_input_tokens**

### Stop Reasons

| Value | Description |
|-------|-------------|
| `end_turn` | Natural completion |
| `tool_use` | Stopped to use a tool |
| `max_tokens` | Hit token limit |
| `stop_sequence` | Hit stop sequence |
| `pause_turn` | Paused |
| `refusal` | Refused request |

## System Messages

```json
{
  "type": "system",
  "uuid": "b1696e28-66dc-4e03-bee0-2484fcce32e6",
  "parentUuid": "71652464-3644-4ec2-9096-f3d3c341d07f",
  "sessionId": "f0fa7faf-f147-4745-bd3d-2e33a785167c",
  "timestamp": "2026-01-13T07:45:46.653Z",
  "subtype": "local_command",
  "content": "<command-name>/ide</command-name>...",
  "level": "info",
  "isMeta": false
}
```

| Field | Type | Description |
|-------|------|-------------|
| `subtype` | string | `"local_command"`, `"stop_hook_summary"` |
| `content` | string | Message content |
| `level` | string | `"info"`, `"warning"`, `"error"`, `"suggestion"` |
| `hookCount` | number | Number of hooks executed |
| `hookInfos` | array | Hook command details |
| `hookErrors` | array | Hook errors |
| `preventedContinuation` | boolean | Whether hook stopped execution |

## Queue Operation Messages

Background task notifications:

```json
{
  "type": "queue-operation",
  "operation": "enqueue",
  "timestamp": "2026-01-13T17:31:56.853Z",
  "sessionId": "f0fa7faf-f147-4745-bd3d-2e33a785167c",
  "content": "<task-notification>...</task-notification>"
}
```

## Common Tools

| Tool | Input Fields |
|------|--------------|
| `Read` | `file_path`, `offset`, `limit` |
| `Write` | `file_path`, `content` |
| `Edit` | `file_path`, `old_string`, `new_string` |
| `Bash` | `command`, `timeout`, `description` |
| `Glob` | `pattern`, `path` |
| `Grep` | `pattern`, `path`, `type` |
| `Task` | `prompt`, `subagent_type` |
| `TodoWrite` | `todos` |
| `WebFetch` | `url`, `prompt` |
| `WebSearch` | `query` |

---

## Session Compaction

Claude Code may compact sessions, rewriting the JSONL with new UUIDs and trimmed content.

**Detection**: Track `first_message_uuid` - if it changes, the file was rewritten.

---

## Parsing Tips

1. **Identify User Prompts**: `type: "user"` where content is NOT `tool_result`
2. **Calculate Tokens**: Sum all token fields for total context
3. **Count Tools**: Look for `type: "tool_use"` in assistant content
4. **Handle List Content**: User `message.content` can be string OR array
5. **Detect Compaction**: Compare first message UUID across imports
